# 给下一轮 Codex 的开发交接

直接读取README、game_design、ending_system、technical_architecture、qa_report，以及tests/report.json；不要从零重造世界。

## 不可破坏的约束

1. 七天且恰好七次核心行动；每天恰好四个可用选项。
2. 同菜单四个行动下一日必须去往不同处境；第七日不能统一成所有路线同样四项。
3. 物品、重大罪责与前史不会因收拢消失。条件终局必须改变实际能力与结果，不能仅改显示文字。
4. 人格隐藏，前六日决定主要取向，完整轨迹优先；具体伤害不能靠属性抵消。
5. 角色死亡、玩家死亡、容器是否交接必须与尾声一致。
6. 世界不能因杀魔王自动得救；真结局结束制度，不物理消灭全部痛苦。
7. 修改编辑源再构建；保持生成JSON可以独立读取，不能把剧情塞进UI。
