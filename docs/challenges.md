# 额外挑战落实情况（含剧透）

| 目标 | 本版处理 | 精确边界 |
|---|---|---|
| 零杀戮通关 | 有可达路径与测试徽记 | 表示没有本局直接致死行动，不声称全大陆零伤亡 |
| 全员存活 | 测试主要具名角色与玩家的死亡状态 | 大多数NPC尚未实现多种死亡，不伪装成完整救全员机制 |
| 不拔圣剑 | 多条路线；独立隐藏称号 | 拒绝过圣剑且从未取得，最终完成勇者救援 |
| 不加入阵营 | 可走自治、流民、渡口 | 合作不等于效忠；徽记排除明确王国／教会效忠、王位／权杖 |
| 成为魔王 | 多个终局入口 | 明确承压与失去自由，不能当作免费晋升 |
| 成为国王 | 王庭、预算、议会等入口 | 都保留权力监督问题，不自动获得全世界承认 |
| 成为教会领袖 | 守誓、禁书、返回异议者入口 | 不是所有信徒都接受改革 |
| 与当前魔王和解 | 证词、照护、同意复核 | 非强制要求所有受害者一起原谅 |
| 旧魔王死亡但世界暂获救 | 尊重停止请求，常备缓冲接压 | 只保住一次冲击；不能当作永久解决 |
| 彻底摧毁深渊 | 不设置已验证成功选项 | 遵守能量与代价守恒，不为凑结局凭空消灭问题 |
| 更深层秘密 | 旧文明的代价转移系统 | 不把魔族血统解释为深渊本源 |
| 前代勇者记忆 | 可接受灌注、保存名字；二周目回声 | 记忆不是客观全知，不重置单局死亡 |
| 龙族真相 | 龙骨支点与旧制度利益 | 守护幼龙不替古龙族群免责 |
| 女神是否真实 | 留有形而上不确定性 | 可证的是征用核心及其行为，而非所有神性来源 |
| 弑神 | 终止曙母强制权 | 失去集中调配带来新成本 |
| 普通人 | 独立身份与隐藏称号 | 日常有价值，不夸大为独自救大陆 |
| 极端理智／仁慈等 | 八维主要行动倾向＋身份 | 不是无代价道德测试；堕落与严重伤害另作不可撤销记录 |
| 人格矛盾 | 温柔暴君、祈祷弑神者等 | 手写白名单，尾声解释矛盾，不随机拼词 |
| 从极端到另一个极端 | 24弧光 | 检验时间次序和后段重复行动，不能仅凭最终分数 |

具体见证路线按最终tests/witnesses.json读取。真结局参考路线：进入旧林 → 放下剑柄测绘 → 请求教会熄灯测波形 → 研究病历寻找分压 → 完成小规模验证 → 逐区确认同意 → 接通自愿分压网络。二周目才有长期转型所需的回声校验；首局同路线只实现暂时稳压。
