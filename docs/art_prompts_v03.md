# V0.3 美术资源与 Premium 后续制作单

## 已实装与使用范围

最终本体视觉为**文字、UI、BGM、少量纹章、特殊结局高质量插画**。正常剧情页只显示NPC首次身份标签，不渲染像素人物卡。14个稳定的 `spriteKey`、节点 `characterIds` 和相遇数据保留为项目资料；先前的原创像素SVG仍在源码包中，但不内嵌到玩家HTML，也不用于本体画面。普通Ending使用小型纹章与文字，`artType=none`、`artKey=null`；不需要大型或像素结局图。先前普通像素图是闲置原型，不属于当前交付视觉。

8个可达特殊称号仍标记 `artType=premium`，缺少实际图片时**不显示图片区域或开发占位**。`assets/endings/premium/` 目前没有已完成插画。下列为逐幅制作说明，不代表图片已经存在。

共同规格：横向16:9或近横向；半写实电影感暗中世纪奇幻；旧铜、湿石、烟、深青黑、炉火旧金；人物真实比例，克制神性和魔法强光；不出现文字、UI、勋章或现代武器；为结局标题和长段文字留出安静背景。涉及儿童和悲剧仅做含蓄叙事，不展示血腥细节。每幅独立构图与光源，不统一做成英雄胜利壁纸。

## 后续资产接入约定

真实插画完成、取得制作与使用权后，以同名文件置入 `assets/endings/premium/`；目前pack支持SVG原生内嵌。若采用PNG/WebP，应在pack的受控mime映射中扩展并验证离线构建。像素角色若重绘，保持14个稳定spriteKey，不改人物或剧情ID；不得把道具视觉当作玩家未得到的证据。
