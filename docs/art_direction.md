# V0.2 美术方向与实现边界

视觉目标是“还在使用的记录与器物”：纸、铜、旧布、木工记号，避免闪耀英雄奖杯。四线共享版式，叙事靠道具和用词区分，不以红绿颜色暗示善恶答案。

| 区域 | 方向 | 本版落地 |
|---|---|---|
| 卷首 | 深墨绿中的旧拱窗与未出鞘黎明 | 保留原 SVG，无外部素材请求 |
| 正文 | 暖纸色、深灰绿字、宽松段距 | 2–3 段独立 p，正文 16–17px，约 1.95–2 倍行高 |
| 昨日回声 | 侧边细金线、次级字色 | 从正文纸面独立出来，不占第一自然段 |
| 选择 | 四块等权按钮，不按价值观着色 | 去掉剧透小字，每个按钮至少 44px 可操作高度 |
| 结局 | 标题、收束、相遇者、世界、个人、七日回看 | 不展示人格分数和人格测试式诊断 |
| 小屏 | 保留文字层级，省去装饰插画 | 420px 下导航独占一行、图鉴单列、长标题换行 |

正文用系统宋体回退栈，导航用系统无衬线；没有在线字体。现有 SVG 为项目内代码资产；没有新增 AI 图片、采购图、版权未明素材。V0.2 不新增插画库。

预定后续素材：王庭湿粮册、圣堂病历、龙骨检修口、渡口工具箱各一张静物。需要确立统一色温、材质尺度和压暗区，让正文仍是视觉中心。未制作，不计入完成数量。

无自动闪烁、无震屏；遵循 prefers-reduced-motion。实际对比度、长段落观感、截图验收未完成，参见 visual_qa_v02.md。
