# V0.2 音频计划（历史资料；V0.3 实装状态见 audio_system_v03.md）

交付 HTML 保持无音频依赖，没有隐性联网和自动播放。以下是后续制作规格，不是已有资产清单。

| 事件 | 声音方向 | 触发与约束 |
|---|---|---|
| 卷首 | 低风与远处木响 | 玩家主动开启声音后才播放，低循环密度 |
| 翻日 | 一次短纸响或绳扣轻碰 | 每次确定行动最多一次；不为善恶分别配奖惩音 |
| 王庭 | 羽笔、远车轮 | 少量空间环境声，不覆盖阅读 |
| 圣堂 | 管道与缺失的钟尾 | 不用恐怖音效替教会预设立场 |
| 龙境 | 铜管热胀、缓慢呼吸 | 死龙路线不可再用可辨认的古龙呼吸 |
| 渡口 | 水、船板、灶火 | 随场景选择一种，不堆叠所有元素 |
| 结局 | 环境声自然衰减 | 不用胜负号角把称号分为唯一正确与错误 |

V0.3 的新玩家偏好默认开启，但加载时不播放，首次用户手势后才开始；音量可调且可一键停用，明确保存的关闭偏好不会自动开启。后台暂停；恢复标签页不自动增加响度。状态变化同时有文字，任何线索都不能只靠听见声音取得。NG+ 回声不增加提示音或机制奖励。

制作建议：自录器物与合法授权环境声，提供授权记录；循环要人工听接缝。可选 OGG/MP3 内嵌会显著增加单文件体积，需单独评估。暂不承诺配乐、配音、循环无缝或听觉无障碍已验收。
