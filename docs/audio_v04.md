# V0.4 音乐交付与验证边界

八首原创曲由项目内`generate_bgm.py`用NumPy合成，没有采样、外部商业配乐或联网请求；合成脚本和母版WAV均在仓库，交付HTML嵌入FFmpeg转换的Ogg Vorbis。主题动机跨曲复现，不同调式、音区、和弦、伴奏密度与段落用来区分故乡、探索、危机和不同终局。五个SFX仍无音源。

每首72秒。`tests/audio_quality_v03.py`检查WAV时长、RMS与峰值；`tests/audio_decode_v04.py`用FFmpeg解码交付Ogg，确认八轨均可解码、时长72秒、非静音、RMS约−16.5dBFS且曲间跨度约0.01dB，峰值低于0.8。Ogg总计约1.3MB，独立HTML约9.1MB；压缩后的接缝需要真人试听。手机扬声器、笔记本、Edge和Android WebView的实际发声与长时间阅读舒适度没有在此环境验收。

加载不调用play。启用偏好与当前会话激活分开；拒绝播放时保留偏好并可重试。切曲按现有900ms淡入淡出，错误保留实际异常。新玩家默认40%音量，旧用户保存的关闭或音量均不改写。
