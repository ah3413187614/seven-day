# 视觉与交互规格

## 美术语言

深墨绿背景（#0b1518）、暗金强调（#d6ba7c）、羊皮纸阅读面（#ece4d2）、低饱和边线。正文使用本地宋体族，界面使用系统无衬线；不依赖网络字体。标题页是代码内嵌的拱窗、光环与圣剑SVG，而非外部图片下载。

节制使用纹样：只有标题拱窗与章首数字承担中世纪气氛，按钮保持现代可读性。没有漂浮金币、发光装备品质、弹出礼包。移动端隐藏装饰图，保持正文与四个行动完整可读。

## 界面清单与已实现交互

- 标题：中文名、英文副题、核心句、开始／继续、图鉴、说明。不会提前透露容器真相。
- Day：七枚日期圆点、地点、章节名、纸色正文。前一日后果单独置于顶部，帮助玩家识别因果。
- 选择：桌面2×2，移动端单列。每个按钮短行动＋一个可预见代价；没有人格标签、最佳答案提示或未来全部后果。
- 日落：全屏遮罩，显示刚发生的后果，点击一次进入次日。无额外叙事分叉，只是确认阅读。动作锁防止双击连续决策。
- 对话与物品：合并在当天正文及日落叙述，重要道具用旗标保存；没有单独背包界面。
- 隐藏内容：周目回声以文字标签标示，绝不只靠颜色；条件终局依然四个按钮，不显示灰色第五项。
- 第七日：使用与平日一致的可读结构。其不同来自行动权限，而非逼迫玩家在倒计时下选。
- Ending Reveal：大字号称号、几项有限挑战徽记、分段尾声、最后一句；不显示算法ID。
- 总结：可展开七日回顾、文字化主行动倾向；隐藏精确分数。
- 图鉴：只列发现的名字，未发现项不泄露标题和条件，不为无可达证明的储备条目占位。

## 可访问性与容错

语义button、中文文档语言、可见键盘焦点、Tab／Enter操作；日落遮罩把键盘焦点留在继续按钮，进入下一日后聚焦标题。prefers-reduced-motion关闭非必要过渡；移动宽度采用自适应布局。

没有背景音乐或音效，不依赖音频表达关键信息。音量选项应随实际音频资产一起加入，不能放一个无效开关。

存档失败给出可读提示并允许导出，不悄悄清空图鉴。导入文件最大100KB，拒绝格式错误、未知版本和非法路径；有未完成旅程时导入要求确认覆盖。重开也提醒覆盖。
