# 阿斯特雷亚世界圣经（DESIGNER_ONLY）

## 不得改变的因果链

古代社会把寒冷、痛苦与灾害的代价从人口中心转移到地下 → 地下形成无法凭意志消除的回流海“深渊” → 为防整体反涌，需要有界的泄压与分配 → 旧系统失去分散接口后，强大生命被用作调节容器 → 七百年前艾德里安接替濒临失效的前任 → 王国与教会把接替写成斩杀 → 容器如今接近承受极限 → 勇者召集兼具救灾动员、政治象征与继任筛选目的。

深渊不是邪恶种族，不是来自魔族血统，也不会因杀死一位魔王而消失。它包含真实能量与被旧系统转移的痛觉记忆，既有物理作用，也会给承压者带来欲望回声。

## 时间表

- 距今约1200年：河谷城市建立曙母分配网络，人口中心逐渐摆脱严寒和部分病痛；边缘地区承担越来越多外部代价。
- 距今约900年：不平等引发断网战争，分散接口损毁，龙骨导管成为少数仍能工作的支点。容器制度作为应急措施出现，随后被长期化。
- 距今700年：被称为魔王的前任容器面临崩解。艾德里安持黎明抵达，发现杀戮会导致失控，选择接替。王国与教会把“继任”改写成“神授胜利”。
- 后续700年：艾德里安一直是同一个主要容器，并非七位勇者先后接替。历史上的后续勇者是候选者、外环承压者或被取消继任的人；相同病历来自同源损伤，不证明换过七位魔王。官方“周期复活”是对历次封印失稳的包装。
- 距今36年：北岸危机。摄政的父亲拒绝强制选拔，却没有同时落实备用泄压与撤离，造成惨剧。这说明善意不足以替代准备，不说明强制选拔天生正确。
- 本周：三条主支点老化且容器无法恢复；测量给出七日内崩解窗口。召集令发布。七天是保守操作窗口，不是精确神谕的天命计时。

## 地理与政治

阿尔维恩王国控制河谷粮仓、王都与征税道路。圣辉教会跨越国境拥有医院、档案与封印维护人员。魔族诸部生活在北方旧泄压区，部分部落因此长期承受污染；这不是他们天然无辜的证明。瓦尔等军阀会利用受害历史压迫同族。

龙族守护高地龙井和祖墓管道，有维护知识，也有回避共同责任的既得利益。精灵长寿使其保留更多古文，但长期以墓地保护为由垄断图纸。边境自由领由商业关卡、逃亡人口与地方议会构成，自由不等于物资自动公平。

本作地点旅行采用紧凑地图：王都—教会—旧林—边境渡口处在同一条河谷走廊，一日能够移动；魔王城不是大陆另一端，而是封印山腹的维护设施及其外围聚居区。不得用一日横跨大陆弥补剧情转场。

## 圣辉宗教与曙母

一般信徒相信女神赐剑、勇者斩魔王、钟声标示神恩。医师与基层教士大多不知道容器真相；少数高层确实知情，但动机从维护秩序、恐惧崩溃到保护权位各不相同。宗教还承担真实的照护与跨地区协调，揭露谎言不会自动创造替代机构。

已证实：曙母核心能计算资源分配、向网络发出征用指令，祭司传声管混入过人为神谕。未证实：一切超自然回应都只是机器，或确实存在独立于机器的女神。弑神结局的可操作对象是拥有强制权的分配意志，不宣称从哲学上证明神不存在。

## 黎明

黎明是能识别承压意志并传导回流的古代器具。它回应“愿为某信念付出生命”的强度，不判断信念是否善。拔剑需一次知情面对死亡的试炼；勇敢的野心家可以通过，口头善良但拒绝承担者未必通过。

剑并非无限能源。可以引导黑潮、作为停火信号、接入阵列、永久折断释放屏障。凡是未取得圣剑的路线，不允许靠“其实一直带着剑”补权限。数据中的物品前史通过took_holy_sword记录；本版未实现剑多次失而复得。

## 魔王与容器

魔王首先是一份职责，后来成为人类妖魔化的称号。魔族不天然服从容器；瓦尔会逼艾德里安支持战争，容器也无法单凭身份取消诸部冲突。容器延长寿命的代价是持续疼痛、自我边界损失、无法正常离开主接口。

杀掉当前容器而不接压，会引发灾害。结局中的和平停止有明确的常备一次性缓冲与撤离队协助；它只能防住一次冲击，不是终结轮回。新的容器或分散网络才可能解决下一轮。玩家成为容器也不代表别人从此有权永远要求他同意。

## 龙族秘密与死亡连续性

龙骨是生物导管，古代龙族同意以单容器代替自身长期承压，因此需要承担历史责任。每一枚龙卵都需要热量，但烧毁村庄不是生理上的唯一选项，是资源与权力分配造成的假二选一。

阿瑟兰可被玩家杀死，幼龙并不随之自动死亡。古龙死亡后，由族群的遗誓使履行外交联系；后续实际界面转换说话者，终局另有赔偿与审判菜单。禁止死者复活签约、禁止以养大幼龙抹掉屠龙。

## 深层真相与真结局边界

旧文明不是凭空创造痛苦，而是把代价从部分人身上转走。彻底炸毁深渊没有已验证可行方法，不设一个“摧毁”按钮完成万事。分压方案接回代价、废除强制征用、让各地有退出权；生活因此更艰难，制度更需要维护。

真结局不是拯救所有曾经死去的人，而是停止不断寻找一个替全世界永久承受的人。全员存活挑战仅能对本版具名主要角色与玩家作有限验证，不能把未知平民伤亡写成零。

## 普通人的认知层次

第一至二日：知道封印危险、召集与地方冲突；不知容器真相。第三日：获得相互冲突的证据，仍可能用神迹解释。第四日：多方证据确认容器职责。第五日：部分研究路线发现旧文明与曙母机制。其他路线可以完成局部救援，不必强迫每个人看完百科全书。第七日：只展示与自己入口和已知行动相关的终局。
